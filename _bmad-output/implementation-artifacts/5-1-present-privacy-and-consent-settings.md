# Story 5.1: Present privacy and consent settings

Status: done

## Story

As a privacy-conscious user,
I want a dedicated settings screen for behavioral detection and data handling,
so that I can control what is collected and when.

## Acceptance Criteria

1. Given the user opens settings, when they review privacy options, then the app explains interruption detection and data storage clearly.
2. The user can turn detection on or off.
3. The settings screen makes consent and data handling transparent.
