# Story 5.2: Explain storage vs ephemeral handling

Status: done

## Story

As a user deciding how honest to be,
I want the app to explain what is saved and what is ephemeral,
so that I can choose the right mode for each reflection.

## Acceptance Criteria

1. Given the user selects reflection mode, when the app displays the option, then it clearly states whether raw content will be stored.
2. Ephemeral entries are labeled as temporary.
3. The explanation is simple, direct, and reassuring.

## Tasks / Subtasks

- [x] Add explanatory copy for storage and ephemeral handling.
- [x] Implement UI labels and descriptions in the reflection mode chooser.
- [x] Ensure users can easily switch between saved and ephemeral modes.
- [x] Validate that the wording avoids fear and emphasizes control.

## Dev Notes

- Make the distinctions clear without overwhelming the user.
- Use plain language and avoid technical jargon.
- Treat ephemeral mode as a first-class privacy option.

### Project Structure Notes

- Integrate this explanation into the reflection mode selection flow.
- Keep the mode chooser state and labels consistent across screens.
