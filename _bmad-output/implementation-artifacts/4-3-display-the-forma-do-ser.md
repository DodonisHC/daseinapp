# Story 4.3: Display the Forma do Ser

Status: done

## Story

As a user reviewing my balance,
I want a qualitative shape visualization,
so that I can sense my current integration without seeing numeric scores.

## Acceptance Criteria

1. Given the user views the balance screen, when the visualization renders, then it shows a shape whose regularity reflects balance.
2. The visualization includes a short interpretive caption.
3. The display avoids gamified scoring and numeric ratings.

## Tasks / Subtasks

- [x] Design the Forma do Ser visualization and caption layout.
- [x] Implement the balance visualization using qualitative shape rendering.
- [x] Add a short text interpretation based on the balance state.
- [x] Ensure the visualization is accessible and understandable.

## Dev Notes

- The visualization should feel expressive rather than evaluative.
- Use shape semantics to communicate balance instead of numbers.
- Keep the caption short, supportive, and non-judgmental.

### Project Structure Notes

- Add the visualization to the balance or insight screen.
- Let the component consume the balance engine's qualitative output.
